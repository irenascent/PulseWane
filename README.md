# PulseWane

Orchestrates distributed, real-time data processing across scalable platforms via an auto-scaling engine.

PulseWane is aimed at developers who need a straightforward, dependable solution.

**Highlights**

- Orchestrates distributed, real-time data processing

- auto-scaling engine

- Pytest for testing

## Installation

1. Clone the repository: `git clone https://github.com/irenascent/PulseWane.git`
2. `cd PulseWane`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure PulseWane, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
